# FY-4A / FY-3C CSI ×4 数据集划分

本目录保存已完成的 DRCT-L ×4 实验所使用的三套**固定样本清单**，是训练、验证和最终测试划分的唯一依据。

```text
fy4a_fy3c_csi_x4/
├── train/
│   └── samples.json       # 固定训练样本：50,000 对
├── validation/
│   └── samples.json       # 固定验证样本：10,000 对
└── test/
    └── samples.json       # 最终独立测试样本：10,000 对
```

每一条清单记录样本的可复现索引、来源日期、批次文件和批次内位置。真实 LR/HR patch 不复制到本目录，默认从仓库根目录下的 `outputs/fy/samples/` 读取；也可以通过环境变量 `FY_CSI_SAMPLES_ROOT` 指向实际数据位置。

验证集包含训练过程中固定监测的 1,000 对样本，并补充 9,000 对按日期分层抽取的样本。最终测试集与完整 10,000 对验证集、训练期固定可视化样本均不重叠；50,000 对训练样本来自与测试集分开的源日期。

这些划分对应已冻结的 epoch 271 实验结果，不应事后改称为 3:1:1 的时间划分。
